SystemShield is a free Windows security auditing tool. It reviews system settings, installed software, browser versions, network configuration, and security features, then presents detections and findings on a risk scale and provide guidance to help the user understand the risks they cause.

This tool is made to stop remote-support scams. If you know someone who you believe is being scammed on their computer, tell them "Try SystemShield."
https://www.SystemShield.net

SystemShield does not remove files directly. Software actions use Windows-registered uninstall entries or Windows Settings shortcuts.
